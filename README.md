# Scientific Calculator Web App 🔢

Full-featured calculator with scientific functions,
unit converter and formula reference library.

## Live Demo
[Click here](https://calculator-webapp-5kf3refyjuktjhz7mvyfhl.streamlit.app)

## Features
- Standard calculator with button UI
- 13 scientific functions (sin, cos, log, sqrt etc.)
- Mathematical constants (π, e, φ, c, g)
- Unit converter — 7 categories, 40+ units
- Formula reference — Math, Physics, Stats, Finance
- Calculation history with CSV download

## Tools Used
- Python, Streamlit, Pandas, Math

## How to Run Locally
pip install streamlit pandas
streamlit run app.py
